# Theme and Back to Top Validation

The desktop navigation now visibly includes a compact black-and-ivory theme switch beside the primary link track, with an explicit pressed state and keyboard focus ring. On mobile, the control is available in the opened navigation panel so the hero header remains uncluttered. The global Back to Top control remains hidden until a visitor has passed the primary section and returns smoothly unless reduced-motion is enabled. Desktop and 390px mobile header checks retained the CORTEX hierarchy without overlap.
