# Gliding Navigation Validation

The selected Home and One-Pager states now render as dark controls in both captured light-mode surfaces, rather than as the earlier ivory active treatment. A page-ground knockout surrounds each active control, visibly severing the horizontal navigation rail on both sides. The shared selection layer uses a spring layout transition before the page navigation completes, so it glides toward the newly chosen location. The mobile header remains compact; the same dark selection treatment appears in the opened mobile grid.
