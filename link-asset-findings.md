# Linked Cortex Site Visual Findings

The linked Cortex landing page does not expose conventional raster image elements. Its visual language is built from CSS and inline vector-style treatments: a warm ivory repeating conic-gradient ray field, compact technical labels, small coordinate-like marks, and sparse monochrome diagrammatic compositions. This makes it possible to adopt its graphic identity without importing the originally supplied still images.

The revision will retain the supplied MP4 as the only source media in the opening scroll story. Outside of that video, the landing page will use original CSS recreations of the linked site’s material-safe graphic vocabulary instead of raster overlays: radial ray fields, line systems, signal bars, and compact technical annotations.

## Initial Scroll Findings

The opening of the linked site uses a dense, warm-ivory radial ray graphic behind the company-brain headline. This visual treatment can replace the current static appliance overlay without adding a raster image, while leaving the scroll-scrubbed MP4 unobstructed. Lower-page asset inspection continues before final selections are made.

## Scroll Structure Findings

The linked page is a scripted, scroll-driven composition rather than a simple document. It contains multiple staged visual acts, including an inline vector appliance-estate scene and separate hero-art/ray fields for Cortex, Conscience, and Cornea. The lower field visual is located near the final 1,100px frame of the 10,856px scroll composition, and will be inspected directly before integration.

## Suite Page Findings

The Suite page follows the same light-on-violet visual system but shifts the central visual from a company-brain composition to a triptych of memory, judgment, and proof. Its hero relies on a radial ray field and inline styled art rather than raster media. The supporting page rhythm is editorial: an opening proposition, three product pillars, a sequence of six utility features, an installation command line, and a ninety-day operating timeline. This provides the structural reference for the project’s Suite page while allowing it to remain visually coherent with the revised dark physical-infrastructure home page.

## Secondary-Page System

The public One-Pager is a long-form technical brief with a violet masthead, warm-paper document body, stamped section labels, a highlighted “in fifty words” quote, and a direct reading rhythm. FAQ and Values use a simpler, question-and-answer or manifesto format. The Edge is a detailed physical-infrastructure page whose subject and editorial sequence closely align with the current cinematic home page. The expanded project will translate these formats into a shared dark physical-infrastructure system, using the linked site’s radial rays, document stamps, signal lines, and outlined artifacts without retaining its violet palette or importing the originally supplied still images.
