# Cortex Cinematic Asset Package

The standalone GitHub export includes a complete `assets/` directory for the **Cortex Cinematic** site. It contains all **29 media, font, logo, and document files actively referenced by the application**, together with the 12 original project materials supplied during the design process.

| Directory | Contents | Intended use |
| --- | --- | --- |
| `assets/site-referenced/` | Runtime assets used by the live site, including images, the 10-second film, logos, a typeface, and the downloadable one-pager. | Use these files when migrating the site away from managed storage or when editing site visuals. |
| `assets/original-project-materials/` | Original shared project source materials, including the initial video, supplied WebP artwork, source notes, and the project changelog patch. | Retain as the source/reference archive for future creative work. |

The asset directory intentionally preserves the runtime filenames used by the current source code. The filename suffixes distinguish the managed-storage versions used by the live site, while the unsuffixed files in `original-project-materials/` preserve the original supplied names.
