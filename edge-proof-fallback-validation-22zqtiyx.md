# Edge Proof Fallback Validation

The filmed Edge appliance proof now supplies an optimized static poster immediately and swaps to that poster if the browser reports Data Saver, a 2G or slow-2G connection, or a video playback error. The poster uses the same physical appliance language and object positioning as the clip, so annotations and responsive framing remain stable. Desktop and 390px mobile checks retained the established Edge composition without layout shift.
